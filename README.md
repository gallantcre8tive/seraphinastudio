# Seraphina Studio

Premium international photography, videography & flying-dress experience website.

**Domain:** [seraphinastudio.eu](https://seraphinastudio.eu)  
**Tagline:** Your Moments. Our World.

## Tech Stack

- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- Fully responsive (mobile, tablet, desktop)
- No build step required

## Quick Start

Just open `index.html` in any modern browser, or serve locally:

```bash
# Python
python3 -m http.server 8000

# Node
npx serve .
```

Then visit `http://localhost:8000`

## Deploy

This is a static site. Deploy the entire folder to any static host:

- **Netlify** / **Vercel** / **GitHub Pages** / **Cloudflare Pages**
- Or any traditional web host

For GitHub Pages:
1. Push this repo
2. Settings → Pages → Deploy from main branch / root
